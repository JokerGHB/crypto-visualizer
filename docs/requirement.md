## 1. 项目背景与目标

### 1.1 背景

AES 是应用最广泛的对称加密算法，但其内部过程对学生不可见：4×4 状态矩阵、S 盒查表、GF(2⁸) 上的列混合、轮密钥扩展，全部发生在一次函数调用之内。学生能看到明文与密文，却看不到中间发生了什么，导致「会调用库」但「不懂原理」。

本项目把 AES 的每一步运算拆开并可视化呈现，同时提供一个能结合当前步骤讲解的 AI 辅导智能体，把抽象算法转化为可观察、可交互、可练习的学习过程。

### 1.2 目标

1. 实现 AES-128/192/256 加解密全流程可视化，覆盖字节替代、行移位、列混合、轮密钥加四步及密钥扩展。
2. 提供逐步播放、单步执行、跳转、调速与参数调节等交互能力。
3. 集成 AI 智能体，实现步骤级讲解与多轮辅导对话，并在服务不可用时降级。
4. 提供用户管理、算法历史记录与回放。
5. 提供交互式练习模块，服务端判分并支持错题回跳。
6. 满足输入校验、XSS、CSRF 防护等 Web 安全开发规范。

### 1.3 范围边界

| 类别 | 内容 |
|---|---|
| 必做 | AES 全流程可视化、S 盒与密钥扩展展示、播放控制、AI 辅导、用户与历史、练习模式、安全防护、测试、部署 |
| 选做（本期未做） | DES / SM4 / RSA 演示、班级看板、题目闯关积分、语音讲解 |
| 明确不做 | 生产级加密工具、密钥托管、移动端 App、i18n、对接教务系统 |

## 4. 非功能性需求

| 类别 | 要求 | 达成情况 |
|---|---|---|
| 性能 | 单次 AES 轨迹生成 ≤ 100 ms | 实测 < 20 ms（纯 Python 实现 40 步） |
| 性能 | 单步切换响应 ≤ 50 ms | 前端仅切换渲染数据，实测无延迟 |
| 性能 | 首屏加载 ≤ 3 s | 生产构建 gzip 后约 44 KB |
| 兼容性 | Chrome / Edge 最新版 | 已验证 Chrome |
| 响应式 | 1366×768 及以上正常显示 | 三栏布局 ≥1280px，1280 以下降为两栏 |
| 可用性 | AI 不可用时核心功能不受影响 | 已实现三种降级场景并有测试 |
| 可维护性 | 前后端分离、契约稳定、算法有单测 | Trace 契约冻结，后端 90 项测试 |
| 安全合规 | 最小必要信息收集，不采集敏感个人信息 | 仅用户名与口令散列 |
| 准确性 | 算法结果与 FIPS-197 标准一致 | 4 条标准向量对拍通过 |

## 5. 约束与假设

1. 运行环境需 Python 3.12+ 与 Node.js 20+。
2. AI 服务需通过环境变量配置 OpenAI 兼容接口；未配置时自动降级。
3. 开发期使用 SQLite，生产建议 MySQL 8。
4. 本期不引入数据库迁移工具（Alembic），建表用 `create_all`，理由见设计文档。

## 6. 验收标准

以「能够演示、能够作答、能够追溯」为判定原则：

1. 四条 FIPS-197 标准向量全部通过，AES-128/192/256 加密与解密结果正确。
2. 步数为 40/48/56，且每步 `stateBefore`/`stateAfter` 首尾相接。
3. 四步操作均可动画呈现，状态矩阵可见逐字节变化。
4. 播放、暂停、单步、跳轮、调速、参数调节均可用。
5. 停任一步都能向 AI 提问并得到与该步相关的内容；断网时降级为本地讲解。
6. 三种题型均可出题、判分、给出解析，标准答案不出现在前端。
7. 历史记录可保存、回放、删除；他人记录访问返回 404。
8. 安全响应头存在，非法输入被拒绝，AI 接口有速率限制。
9. 全部单元测试与接口测试通过。
10. 系统可部署并公网访问。
